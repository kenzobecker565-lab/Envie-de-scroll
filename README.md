# Scroll-up · APK de présentation (hors ligne)

**[Télécharger Scroll-up.apk](https://github.com/kenzobecker565-lab/Envie-de-scroll/raw/apk/Scroll-up.apk)** (Android 8 ou plus récent)

L'application complète (version develop) fonctionne **sans Internet, sans Telegram et sans serveur**.
Tes passions, tes créations et tes dessins restent sur ton téléphone.

1. Télécharge le fichier sur ton téléphone Android.
2. Ouvre-le ; si Android le demande, autorise ton navigateur à installer des applications.
3. Lance **Scroll-up** et choisis tes passions.

Code source et construction : `android/offline/` et `offline/` sur la branche `develop`.
