# Logic studio artwork

Fifteen original 2D editorial illustrations for the approved Scroll-up scenarios.
Generated with the built-in image generation tool, using the approved puzzle UI board as a style reference. No third-party puzzle illustrations are copied.

Prompt: production atlas of fifteen independent narrative illustrations, five columns by three rows; cream, plum, violet, mint and gold, hand-drawn editorial 2D; no interface, mascot, title or numbering. Subjects in order: witnesses; coded letter; photograph and magnifier; electric circuit; parcel and map; metro; painting and inventory; phone and agenda; lighthouse; workshop; observatory; midnight train; expedition; auction; space station.

The generated atlas was inspected, its actual cell boundaries measured, and each cell exported to a 384 × 384 WebP. Runtime assets are `logic-case-1.webp` through `logic-case-15.webp`. The source generated illustration is not required by the application.

Catalogue and case headers use the same individual illustration. Images are decorative; every playable clue and rule is rendered as selectable, accessible interface text. Artwork is never a source of pixel-level evidence.

French, drawing, writing and piano catalogue thumbnails use the application's native icon system and CSS paper illustrations. The existing Minuton art remains unchanged; hint panels use `minuton-approved.webp`.
