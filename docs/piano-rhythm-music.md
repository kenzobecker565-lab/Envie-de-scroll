# En rythme — music references

The development library uses short monophonic adaptations of historical compositions and traditional themes. All audio is generated at runtime with the app’s Web Audio synthesizer. No commercial recording, sampled performance or external MIDI/audio file is bundled.

| Theme | Composition / reference edition |

Sources checked on 2026-10-13. The game labels these as adapted excerpts: it does not reproduce full arrangements. Beats and tempos are deliberately adapted for interactive play. Modern third-party arrangements and recordings may have separate rights and must not be added on the strength of the underlying composition’s status.

The old original melodies remain available by ID only, so existing sessions and gallery entries continue to resolve. They are not shown in the new selection.
